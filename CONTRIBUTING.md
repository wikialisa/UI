# Hướng dẫn Đóng góp (Contributing Guidelines)

Chào mừng bạn tham gia đóng góp cho **WikiAlisa Kit** — bộ công cụ All-in-One Atomic Design System & UI Kits do **WikiAlisa** nghiên cứu, thiết kế và phát triển.

## 1. Bản quyền & Định danh
- **Tác giả & Đơn vị phát triển**: WikiAlisa (`wikialisa`)
- **Dự án**: WikiAlisa Kit (`https://github.com/wikialisa/kit`)
- **Website Showcase**: `https://wikialisa.github.io/UI`

## 2. Quy trình làm việc
1. Fork repository và tạo nhánh mới từ `main`:
   ```bash
   git checkout -b feature/ten-tinh-nang
   ```
2. Đảm bảo tuân thủ tiêu chuẩn:
   - Sử dụng biến màu và khoảng cách từ `tokens/` (không dùng mã màu hex cứng).
   - Đảm bảo Touch Target tối thiểu 48x48pt cho môi trường di động.
   - Kiểm tra hiển thị tương thích cả hai giao diện Sáng / Tối (Light & Dark Mode).
3. Tạo Pull Request (PR) kèm mô tả chi tiết các thay đổi.
